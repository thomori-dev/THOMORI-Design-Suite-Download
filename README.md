# THOMORI Design Suite – Download

CAD und Design in einem Programm für Windows 10/11 (64 Bit) und macOS 12 oder neuer.

**[⬇ Neueste Version herunterladen](https://github.com/thomori-dev/THOMORI-Design-Suite-Download/releases/latest)** – unter „Assets“ die passende Datei laden:

| System | Datei |
|---|---|
| Windows 10/11 (64 Bit) | `THOMORI-Design-Suite-Setup.exe` |
| Mac mit Apple Silicon (M1–M4) | `THOMORI-Design-Suite-Mac-AppleSilicon.dmg` |
| Mac mit Intel-Prozessor | `THOMORI-Design-Suite-Mac-Intel.dmg` |

Welcher Mac? Apple-Menü  › Über diesen Mac: steht dort „Chip“, ist es Apple Silicon, steht dort „Prozessor … Intel“, ist es ein Intel-Mac.

Die Suite benötigt einen Lizenzschlüssel. Lizenzen gibt es unter https://thomori.com – eine Lizenz gilt für 2 Geräte (Windows und Mac gemischt möglich).

**Windows:** Installer starten (bei „Der Computer wurde durch Windows geschützt“ → „Weitere Informationen“ → „Trotzdem ausführen“), dann auf der Startseite „Lizenz eingeben“ und „Aktivieren“.

**Mac:** DMG öffnen und „Thomori Design Suite“ in den Ordner „Programme“ ziehen, dann aus „Programme“ starten. Meldet macOS beim ersten Start, dass die App nicht überprüft werden kann: Meldung mit „Fertig“ schließen → Systemeinstellungen › Datenschutz & Sicherheit › ganz unten „Dennoch öffnen“ → mit Passwort/Touch ID bestätigen (nur beim ersten Start nötig). Danach auf der Startseite „Lizenz eingeben“ und „Aktivieren“.
