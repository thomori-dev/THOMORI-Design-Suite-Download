# THOMORI Design Suite – Download

CAD und Design in einem Programm für Windows 10/11 (64 Bit).

**[⬇ Neueste Version herunterladen](https://github.com/thomori-dev/THOMORI-Design-Suite-Download/releases/latest)** – unter „Assets“ die Datei `Thomori Design Suite Setup ….exe` laden.

Die Suite benötigt einen Lizenzschlüssel. Lizenzen gibt es unter https://thomori.com – nach dem Kauf: Installer starten (bei „Der Computer wurde durch Windows geschützt“ → „Weitere Informationen“ → „Trotzdem ausführen“), dann auf der Startseite „Lizenz eingeben“ und „Aktivieren“.
